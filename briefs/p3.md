# P3 Brief: Benchmark Leaderboard & Methodology Note

## Owner
Person 3 (P3)

## Objective
Produce an honest, reproducible model benchmark that scores every
candidate model on the shared 5-fold OOF splits and writes a two-page
methodology note for the submission.

## Scope
- Classification sweep: Dummy, LogReg, RF, ExtraTrees, HistGB, CatBoost,
  XGBoost, LightGBM — across three feature sets
- Regression sweep: Dummy, Ridge, ElasticNet, Huber, RF, ExtraTrees, HistGBR,
  CatBoost, XGBoost, LightGBM, SVR, PolyRidge(d=4) — across three feature sets
- Four explicit ablations (Valid-only vs all, S4 inclusion, Duration inclusion, poly degree)
- Same fold_indices from src/contract.py — no regeneration
- Ranked leaderboard CSV and six charts
- Two-page methodology note (methodology.md)

## Public API (no API — P3 ships a script, not a library)
- Run: python src/benchmark.py

## Files Owned by P3
- src/benchmark.py         — benchmark engine
- briefs/p3.md             — this file
- tests/test_p3.py         — smoke tests
- methodology.md           — two-page methodology note
- outputs/model_comparison.csv
- outputs/charts/          — six charts
- verification/p3_report.txt

## Acceptance Criteria
1. benchmark.py runs start to finish without error
2. model_comparison.csv has >= 25 rows
3. Every row scored using fold_indices from src/contract.py
4. Both lanes include a Dummy baseline
5. All four ablations appear in the table
6. Classification ranking by Invalid-class F1, not accuracy
7. All six charts exist in outputs/charts/ and are non-empty
8. methodology.md under two rendered pages, all six sections present
9. Methodology note cites >= 8 specific measured numbers
10. src/contract.py unchanged; folds.csv unchanged
