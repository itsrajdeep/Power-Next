# P3 Brief: Benchmark Leaderboard & Methodology Note

## Owner
Person 3 (P3)

## Objective
Produce an honest, reproducible model benchmark that scores every
candidate model on the shared 5-fold OOF splits and writes a two-page
methodology note for the submission.

## Scope
- Classification sweep: LogReg, RF, ExtraTrees, HistGB, CatBoost,
  XGBoost, LightGBM, + P1 Rule-Based Detector
- Regression sweep: Ridge, ElasticNet, Huber, RF, ExtraTrees, HistGBR,
  CatBoost, XGBoost, LightGBM, + PolyRidge(d=3), + Blend
- Same folds.csv used by all workstreams — no regeneration
- Ranked leaderboard CSV and leaderboard charts
- Two-page methodology note (methodology.md)

## Public API (no API — P3 ships a script, not a library)
- Run: python src/benchmark.py

## Acceptance Criteria
1. All classification models scored; leaderboard sorted by F1 desc
2. All regression models scored; leaderboard sorted by MAE asc
3. model_comparison.csv has >= 19 rows (8+1 clf + 9+1+1 reg)
4. methodology.md <= 2 printed pages (~1200 words)
5. src/contract.py unchanged
6. folds.csv unchanged
