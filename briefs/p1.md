# P1 Brief: Sensor Digital Twin & Invalid Detection

## Owner
Person 1 (P1)

## Objective
Build a deterministic sensor digital-twin model that detects Invalid test
measurements using polynomial Ridge regression residuals and rule-based
fault classification.

## Scope
- Fit polynomial Ridge twins for Sensor_S1, S2, S3 from operating inputs
- Compute robust residuals and spike scores
- Derive adaptive empirical-gap threshold from training data only
- Apply fault-rule precedence: missing_sensor → duplicate_vector → sensor_spike → none
- Perform 5-fold out-of-fold evaluation using shared folds.csv
- Final fit on all Valid training data

## Public API (defined in src/contract.py)
- `fit_twin(train_df, *, alpha, degree, random_seed) → dict`
- `sensor_residuals(df, twin_state) → DataFrame`
- `predict_validity(df, twin_state) → DataFrame`

## Files Owned by P1
- `src/p1_twin.py` — main implementation
- `tests/test_p1.py` — acceptance and unit tests
- `outputs/p1/` — OOF predictions, metrics, diagnostics, charts
- `briefs/p1.md` — this file

## Acceptance Criteria
1. OOF taxonomy: 15 missing_sensor, 24 duplicate_vector, 95 sensor_spike
2. OOF precision, recall, F1 for Invalid = 1.0
3. All tests pass deterministically with seed 42
4. No target leakage, no fold leakage
5. src/contract.py unchanged
6. folds.csv unchanged
